# Independent QR reference matrices

Generated by `python3 scripts/qr-goldens.py` using `/usr/bin/qrencode` 4.1.1:
`qrencode -l M -8 -m 0 -t ASCIIi`, bytes supplied on stdin.

Each `.qr`: first line is the exact input in hex; remaining square rows use `1`
for dark and `0` for light, without a quiet zone. These are independent fixtures,
not output from `src/qr.rs`. The Rust test reads the reference mask from its BCH
format information and forces it before comparing every module.

22 cases: one byte; a realistic Tailscale HTTPS URL; non-ASCII UTF-8; exact byte
capacities of all ten versions (14, 26, 42, 62, 84, 106, 122, 152, 180, 213); and
capacity plus one for versions 1–9. Boundary data cycles ASCII bytes 33–122 to
exercise byte mode, interleaving and mixed-length blocks without encoding guesswork.

Own-mask agreement is reported separately, not forced. See
`docs/parity-2026-11/M3.3-pair-device.md` for scoring differences and independent
zbar decoding of our symbols and the rendered app dialog. `scripts/qr-verify.py`
is not a CI Rust test: it needs external `zbarimg` and ImageMagick.
