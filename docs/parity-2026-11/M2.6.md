## What changed

- **Terminal font → Choose…**: anchored picker, case-insensitive name search,
  **Monospaced / All fonts**, saved-family check, keyboard selection, Escape and
  focus return. Proportional saved families open All fonts. The list is
  virtualized and the current family is revealed on opening.
- One **highlighted-family sample**, requested through Rune's named-family
  resolver. List rows deliberately keep the UI font: the picker does not load
  every installed face just to display names. The sample says **“Requested face
  · unavailable glyphs may fall back”**. A test verifies the named IBM Plex
  sample uses bundled IBM Plex bytes, not a falsely labelled Inter face.
- Font style: Regular, Italic, Bold, Bold Italic. **Advanced font settings**:
  line height −20…+100%, character spacing −3…+12 points or −30…+100%, and Both /
  Bold only / Italic only / Neither for program-set attributes. Suppressing a
  program attribute preserves the chosen ordinary face, not necessarily Regular.
- Ordered fallback list: Add from All fonts, disable already-added/primary
  choices, move up/down, remove, and mark unavailable families. Family and list
  changes save now and apply **on reopen**. Help distinguishes saved/active
  values and launch overrides. A missing long family gets its own truncated
  line and Not installed chip, rather than squeezing the label/helper column.
- Advanced participates in the existing search registry and Back/Forward
  history. Search can land on a particular control. Back restores focus to the
  disclosure when appropriate; Escape returns to Terminal without adding a
  duplicate parent stop when that stop is already the previous one. Nested
  pickers dismiss and return focus before the Settings page does.

### Persistence and defaults

`font_family`, `font_size` and `font_fallbacks` remain top-level. The new block is
`terminal.font` (shown at defaults):

```json
{
  "style": "regular",
  "line_height": 0,
  "spacing": 0,
  "spacing_unit": "px",
  "bold_italic": "both"
}
```

`px` is the preserved serialized name for **logical points**, not device pixels.
Missing fields and unknown enum variants use defaults; numeric values are
bounded when used. Tests cover old, partial, unknown-enum and round-trip files,
including retention of cursor, selection, generated titles and top-level font
keys. `--font` and repeatable `--font-fallback` retain their precedence. Opening,
searching, previewing or cancelling a picker neither saves a choice nor sends a
server command. Choosing a family/list order does not swap fonts in-process.

### One grid, no ownership change

`Workspace::metrics()` supplies the effective cell and style. Height scales the
existing rounded natural row height; spacing changes width and glyph inset.
The defaults keep the existing advance, `ceil(size × 1.4)` height and style.
The same metrics reach terminal text, Settings previews, device-pixel sprites,
cursor, selection, search highlighting/find placement, link/mouse coordinates,
compatibility scrolling and size reports. Find placement refreshes locally even
when an unowned pane will receive no resize reply. Text inset/leading do not
move the sprite cell edges.

The glyph-fit cache includes style, cell width and font epoch; ASCII is no longer
assumed to fit a fixed cell when All fonts allows a proportional face. Terminal
rows remain content-memoized. Program bold/italic flags and the chosen base face
are tested in combination.

Only a changed cell size triggers preference-driven resize checks. Existing
owner/initial-attachment rules decide whether anything is sent; preferences
never send an ownership request, replay input, or invent split geometry. The
private live test separately demonstrates explicit terminal input reclaiming
ownership, **not** the preference change doing so.

## Enumeration and performance evidence

`fonts::installed()` caches one `fc-list` result per process with `OnceLock`.
The query requests family and spacing metadata, not every font file. Names are
deduplicated case-insensitively. Fixed-pitch classification requires every
listed face to report fontconfig spacing 90, 100 or 110; proportional/mixed
families stay in All. Bundled IBM Plex Mono and Inter remain available when
fontconfig cannot run. A fresh child-process test with an empty PATH verifies
that fallback without contamination from the process-wide cache.

On this machine: **2,487 face records, 364 families, 24 fixed families, 56,660
bytes**; five metadata subprocess runs took **12.78–13.57 ms**. This measures
`fc-list`, not end-to-end picker latency. A synthetic thousands-of-families test
bounds rendered rows and verifies revealing a distant current choice; it is
not a timing claim for a machine with thousands of actual font files. Selected
samples resolve lazily and named-family strings are interned. No periodic scan,
eager all-file mapping, or per-frame fontconfig process was added.

## Limits and deliberately unchanged behavior

- Font installation/removal needs a new process to refresh the catalog. Failed
  enumeration leaves bundled choices; there is no background retry service.
- A requested face does not guarantee every glyph exists in it. Fontconfig/Rune
  fallback or synthesis may supply missing glyphs/styles. Style choices are the
  four conventional styles, not a variable-font axis editor or an inventory of
  every installed weight. Missing families are not offered as fake installed
  samples. Custom names can still be supplied through config/CLI.
- The picker offers one selected-face sample, not eagerly face-styled rows for
  the whole catalog. At minimum height the anchored list has few visible rows;
  search, scrolling and keyboard navigation remain available.
- All fonts intentionally permits proportional families; the terminal is still
  a fixed cell grid. Negative spacing/leading can intentionally crowd glyphs.
- Live native acceptance here is X11 at 1×. Offscreen 2× captures and fractional
  sprite geometry tests do not establish live Wayland/HiDPI/IME coverage.
- Independent vendored SDK tests and every unrelated external integration
  script were not rerun; no vendored source changed. Full application/library
  tests, protocol builds and the private live regressions above were run.
- Evidence images and logs remain local artifacts at the paths above, not
  checked-in binaries or a release announcement.
