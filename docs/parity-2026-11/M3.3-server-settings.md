# M3.3 — first, read-only Server settings slice

Parent: `9af5bf5` (0.7.4 / #74). Verification: 2026-11-12, Pacific Standard Time.
This is a partial M3.3, **not** Pair QR or server management. No release work.

## Shipped behavior

Settings → **Server** is the first sidebar group, using the existing authored
server glyph. Interface remains the default page. The normal Settings history,
search, focus, keyboard handling and scrolling apply. Search indexes actual row
labels, not private host values. No new command or remote permission is registered.

The page reads the **active** saved host and `HostModel.server_info`:

- Configured host, fixed-word connection state (shared with About), and configured
  address. An SSH endpoint is the saved SSH destination, never the local forward.
- Server version, negotiated API revision while connected, reported supported
  range, platform, commit, clean/modified build and build timestamp.
- Reported PID, start timestamp and session count — not a count inferred from the
  client's session list, and not a ticking uptime.
- Reported listener count and sanitized configured endpoints.
- The **server's built-in Tailscale** state, HTTPS state and reported HTTPS address.
  This is not the client's local Tailscale discovery state.

All cached server facts are described as **last reported**, even while connected.
Disconnected pages explicitly say these facts do not mean the server is running
now; disconnected Tailscale/HTTPS states also carry “(last reported)” inline.
Pending reads say “Waiting for report” only while connected. Refused, timed-out,
missing and partial fields say “Not reported”. Unknown Tailscale states are treated
as starting and unknown HTTPS states as pending, as the SDK specifies. Missing
Tailscale does not imply disabled; an empty listener vector does not imply zero
listeners (older APIs omit it). A new connection uses the existing cache reset;
no information from a previous host or connection is used to fill missing facts.

Values stack below labels, truncate within the page and retain full, sanitized
selectable text/tooltips. A **Copy** button exists only for a usable configured or
Tailscale address, and copies only on explicit activation. It is local clipboard
work, not a registered server action. Reported addresses are never links.

### Privacy and scope limits

`url::Url`, already a dependency, removes URL user information (including the SSH
username), query and fragment. Known URL schemes and literal IP socket addresses
are displayed; unsupported/malformed configured addresses say “Address unavailable”,
while unsupported listener syntax says “Endpoint format not shown”. Absolute Unix
socket paths are preserved literally, including spaces, non-ASCII characters, `?`
and `#`, matching the transport rather than URL query/fragment rules. Address
copies remove URL credentials but preserve paths; they are descriptions, not a
promise that the endpoint can be reached or that its original authenticated URL
can be reconstructed. The existing `endpoint_label` is only a host-name formatter,
not a full-address sanitizer, so it cannot safely serve these copy rows.

No configuration, environment, authentication URLs, Tailscale errors/accounts,
host/instance IDs or raw connection errors are rendered. No endpoint is inferred
from a local SSH tunnel, DNS name, local Tailscale status or listener binding.

Deliberate omissions keep this slice small:

- Listener bound addresses, transport/admission descriptions and per-listener
  copy; unfamiliar listener endpoint syntaxes are not echoed as raw text.
- Tailscale login/approval links, account, tags, control server and DNS detail.
- Uptime and timezone conversion: build/start timestamps are shown as reported,
  retaining their offset; there is no new clock, process read or time dependency.
- Pair QR, server start/stop/configuration, session operations, refresh controls,
  logs, protocol extensions and diagnostics panels.

The page performs **no requests**. It reuses the existing bootstrap status and
one-per-connection Identify/version path already used by About. The existing
Tailscale-event status refresh is unchanged. About's presentation and copied
reports are unchanged; only its fixed-word state helper is shared.
